# Attributions

The phoneme recordings in `public/phonemes/*.m4a` are built from **real human
recordings** hosted on Wikimedia Commons. Each final sound is concatenated from
one or more single-phoneme "unit" recordings with ffmpeg (e.g. `qu` = /k/ + /w/,
`ai` = /e/ + /i/). The exact unit chain for every sound is captured
machine-readably in `public/phonemes/attribution.json` (regenerated by
`scripts/fetch_audio.mjs`).

## License

All unit recordings are in the **public domain / CC0** — released by their

## Tooling

- **ffmpeg** (LGPL/GPL build) — concatenation + AAC encoding, run locally.
- **Wikimedia Commons** — file hosting; downloads via the Commons API and
  `Special:FilePath` with a polite User-Agent and rate-limit backoff.

## Structure reference

The card layout and category naming follow the free
[Read Naturally "Phonics Sounds"](https://www.readnaturally.com/phonics-sounds)
reference page. Their page structure informed our organization only — no
content or audio was copied from Read Naturally.
